# Alokdia High School — Frontend

This folder contains the website UI (React + TypeScript + TanStack Start + Tailwind).

## Run
1. Install Node.js (LTS).
2. Copy `.env.example` to `.env` and fill in the frontend-required values.
3. Run `npm install`
4. Run `npm run dev`

The original frontend uses the API service at `http://127.0.0.1:8765` (see source configuration).
